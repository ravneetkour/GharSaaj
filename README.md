# GharSaaj – Home Products Store

GharSaaj is a beautifully designed, single-page e-commerce web application for home products. Built entirely with Vanilla JavaScript, HTML, and CSS, it dynamically generates over 1000 products across various categories and supports multiple regional languages.

## 🌍 Live Demo
[View Live Site](https://ravneetkour.github.io/GharSaaj/)

## ✨ Features

* **Multi-language Support:** Users can seamlessly toggle the interface and product names between English (EN), Hindi (HI), and Punjabi (PA).
* **Dynamic Product Catalog:** Generates 1000+ curated home products with unique localized names, prices, and ratings using a seeded randomizer.
* **Categories:** Filter items by distinct categories including Furniture, Kitchen, Electronics, Decor, Bedding, and Lighting.
* **Search & Sort:** Fully functional search bar and sorting dropdown (Featured, Price: Low to High, Price: High to Low, Top Rated, A-Z).
* **Interactive Cart:** Features a sliding cart drawer that allows users to add items, adjust quantities, remove products, and view real-time subtotal and total calculations.
* **Pagination:** Easily navigate through the extensive catalog with built-in pagination displaying 40 items per page.
* **Responsive Design:** A fully mobile-friendly layout with a hamburger menu and an adaptive product grid.
* **Smooth UI/UX:** Includes interactive hover animations, toast notifications for adding items to the cart, and a "Scroll to Top" button.

## 🛠️ Tech Stack

* **HTML5:** Semantic HTML structure.
* **CSS3:** Custom properties (variables) for consistent theming, Flexbox, CSS Grid, keyframe animations, and backdrop filters.
* **Vanilla JavaScript:** Handles DOM manipulation, state management (cart, language preferences, pagination), and complex mock data generation entirely without external libraries or frameworks.
